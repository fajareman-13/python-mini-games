
# Trivia Quiz

A simple command-line trivia quiz built with Python for programming practice.

## About the Project

The quiz presents a series of questions and asks the player to enter an answer. It checks each response and displays the final score at the end.

## Concepts Practiced

- Dictionaries
- User-defined functions
- Loops
- Conditional statements
- String methods (`strip()` and `lower()`)
- Score tracking

## How to Run

1. Make sure Python is installed.
2. Open a terminal in the project folder.
3. Run:

```bash
python trivia_quiz.py
```

## Learning Purpose

This project helped me practice storing data in a dictionary, using functions to check answers, iterating through questions, and tracking a score.
