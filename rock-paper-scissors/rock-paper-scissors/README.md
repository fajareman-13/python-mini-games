
# Rock Paper Scissors

A simple Rock Paper Scissors game built with Python as part of my Python revision and practice.

## About the Project

This is a command-line game where the player chooses rock, paper, or scissors, and the computer randomly selects its choice. The program compares both choices and displays the result.

## Concepts Practiced

- Variables and user input
- Lists
- The `random` module
- Conditional statements (`if`, `elif`, `else`)
- String methods (`lower()`)
- Basic input validation

## How to Run

1. Make sure Python is installed.
2. Open a terminal in the project folder.
3. Run:

```bash
python rock_paper_scissors.py
```

## Learning Purpose

This project helped me practice conditional logic, random selection, and handling user input in Python.
