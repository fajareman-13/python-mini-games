
# Mad Libs — Story Generator

A simple interactive story generator built with Python.

## About the Project

The program asks the player to enter a noun, verb, adjective, and place. It uses these words to create and display a short, personalized story.

## Concepts Practiced

- User-defined functions
- Variables and user input
- F-strings
- String formatting
- Basic input and output

## How to Run

1. Make sure Python is installed.
2. Open a terminal in the project folder.
3. Run:

```bash
python mad_libs.py
```

## Learning Purpose

This project helped me practice functions, user input, and inserting variables into a formatted string.
